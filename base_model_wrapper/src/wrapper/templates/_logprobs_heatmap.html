{# Shared per-token logprobs heatmap primitive (ACS-148 / ACS-164). Both the loom (tree exploration) and compare (N-lane) pages colour generated tokens by probability and show ranked alternatives on click — this is the one copy of that logic. Include it once per page: {% include "_logprobs_heatmap.html" %} then call ``window.acsAppendHeatmap(container, entries[, fallbackText])`` where each entry is ``{token, logprob, top: [{token, logprob}, ...]}`` (the shape the loom returns server-side and compare flattens client-side). The script is idempotent (safe if a page somehow includes it twice) and creates its own floating popover + outside-click dismiss, so callers need no extra markup. #}
